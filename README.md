# BR-POP-PWA

Progressive Web App desenvolvido com HTML, CSS e JavaScript.

## O que o projeto demonstra

- Estrutura de PWA com `manifest.json`;
- Interface web com páginas inicial, cadastro, contato e informações;
- Experiência adaptada para dispositivos móveis e desktop.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Web App Manifest

## Como executar

Abra `index.html` em um navegador ou sirva o projeto com um servidor local para testar o comportamento de PWA.
