# BR-POP-PWA

Este repositório contém um Progressive Web App (PWA) chamado "BR-POP-PWA", desenvolvido com HTML, CSS e JavaScript.

## Descrição do Projeto

O projeto é um PWA, o que significa que ele pode ser instalado em dispositivos móveis e desktops, oferecendo uma experiência de usuário similar a um aplicativo nativo, mas construído com tecnologias web. A presença de `manifest.json` e `service worker` (implícito pelo conceito de PWA e `app.js` / `index.js`) confirma essa natureza. O site inclui páginas como `cadastro.html`, `Pag-contato.html`, `sobre-nos.html` e `index.html`, sugerindo funcionalidades de um site institucional ou de serviço com interação do usuário.

## Funcionalidades

*   Experiência de aplicativo nativo via PWA.
*   Página inicial.
*   Página de cadastro.
*   Página de contato.
*   Página "Sobre Nós".
*   Design responsivo.

## Tecnologias Utilizadas

*   **HTML5:** Estrutura das páginas web.
*   **CSS3:** Estilização e layout.
*   **JavaScript:** Interatividade no frontend e lógica do Service Worker.
*   **Progressive Web App (PWA):** Para capacidade offline e instalação na tela inicial.

## Como Configurar e Rodar o Projeto

Para configurar e executar este projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/DAVIWENDELL/BR-POP-PWA.git
    cd BR-POP-PWA
    ```
2.  **Abra o arquivo `index.html`:**
    Simplesmente abra o arquivo `index.html` em seu navegador web preferido. Para testar as funcionalidades de PWA (como instalação e offline), é recomendável usar um servidor local (por exemplo, `python3 -m http.server`) e acessar via `localhost`.
